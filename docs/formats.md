# File formats

To be verified against real (anonymized) fixtures **before** writing parsers.
Record every finding here with the game version it was checked against.

- `profile.sii` — active mods (`active_mods`), load order
- `config.cfg` — `g_save_format`
- `game.log.txt` — mod loading, warnings, version mismatches
- crash logs — exception type, address
- `manifest.sii` — mod name, version, compatible game versions
